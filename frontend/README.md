# frontend

Vue 3 + Vite + Leaflet поверх тайлов OpenStreetMap. Сейчас это стенд для проверки
расчёта расстояний и времени в пути: кликаете точки на карте, получаете маршрут.

## Структура (`src/`)

```
api/         — HTTP-клиент к бэкенду (travelApi.js)
components/  — RouteMap (карта и отрисовка), RouteControls (выбор транспорта и кнопки),
               RouteSummary (пробег, время, провайдер)
composables/ — useRoutePlanner: состояние точек, запросы, ошибки
utils/       — polyline.js: декодер encoded polyline
```

## Запуск

Вместе со всем стеком из корня репозитория: `docker compose up` → http://localhost:5173

Локально (бэкенд должен быть доступен на :8000):

```
npm install
npm run dev
```

Фронт всегда ходит на относительный `/api`, в дев-режиме его проксирует vite
(`vite.config.js`), поэтому CORS в браузере не возникает. Адрес бэкенда задаётся
переменной `VITE_API_TARGET`.

## Что важно знать про отрисовку

- **Геометрия приходит как encoded polyline с точностью 6 знаков.** У Leaflet и Google
  по умолчанию 5 — если перепутать, координаты уедут в десять раз. Проверено на реальном
  ответе: концы декодированной линии совпадают с запрошенными точками с точностью 2 м.
- **Участки маршрута раскрашены по очереди** — видно, где кончается одно плечо и
  начинается следующее.
- **Если Valhalla недоступна**, бэкенд отвечает `provider: haversine` и пустой геометрией.
  В этом случае рисуется серый пунктир по прямой и выводится предупреждение — оценочные
  цифры не должны выглядеть как настоящий роутинг.
- Кнопка «Матрица» показывает сумму плеч по матрице рядом с пробегом из `/route`:
  расхождение видно глазами, оно там есть и это ожидаемо (см. backend/README.md).
